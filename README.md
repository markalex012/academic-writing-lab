# מעבדת הכתיבה / Academic Writing Lab

Hebrew educational website adapted from the supplied 44-page Academic_Writing_AI_Unit.pdf (17 October 2026).

Four lessons, sensor dossier, independent draft/feedback/revision workspace, six games, three role simulations, APA exercises, six prompts, verification and disclosure logs, battery transfer, weighted 0–4 rubric and source review reading status. No live AI or account required. Numeric/choice checks are distinct from human assessment of reasoning.

Live: https://markalex012.github.io/academic-writing-lab/

Open index.html locally; no installation or server required. Work stays in browser localStorage; JSON and sensor CSV downloads available.

Checks: `node test.cjs`; syntax checks on *.js. Original PDF and extracted text remain local outside public dist. Companion Python files mentioned in the PDF were not supplied; the site independently reproduces the provided table summaries in JavaScript, not raw signal measurements. Research/provider/legal descriptions retain the dated guide's limits, not new current advice.
